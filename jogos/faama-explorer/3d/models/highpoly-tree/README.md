# Árvore HighPoly — FAAMA Explorer 3D

Esta pasta contém os arquivos de modelo e textura usados pelo carregador FBX em `../../main.js`.

## Arquivos necessários

Coloque **diretamente nesta pasta**, sem subpastas adicionais:

- `SM_HP_Tree.FBX`
- `T_HP_Tree_Leaf.PNG`
- `T_HP_Tree_Trunk.PNG`
- `T_HP_Tree_Trunk_normal.PNG`

## Instalação

Extraia o ZIP original e copie os quatro arquivos acima para esta pasta.

Abra `jogos/faama-explorer/3d/index.html` por um servidor local (por exemplo, Live Server), não pelo protocolo `file://`.

A mensagem **Árvores HighPoly carregadas** indica que o carregador concluiu a importação. Se os arquivos não forem encontrados, o jogo mantém as árvores provisórias.

## Git

Arquivos extraídos no computador **não aparecem no GitHub** até serem adicionados e enviados por commit. Antes de publicar os arquivos do pacote, confirme que a licença permite redistribuí-los.
